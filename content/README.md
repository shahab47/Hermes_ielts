# Content Repository

This directory contains IELTS preparation content, prompt definitions, rubric descriptors, and validation schemas.

---

## Directory Structure

- `seed/`: Seed data for IELTS band descriptors, sample prompts, micro-skill drills, and curated vocabulary targets.
- `schemas/`: JSON schemas validating item types, question formats, and diagnostic criteria.

> [!IMPORTANT]
> Do not store copyrighted practice materials without explicit licensing. Rely on official public criteria, open educational resources, and internally authored prompts.
