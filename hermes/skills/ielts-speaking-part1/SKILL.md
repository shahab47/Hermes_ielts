# IELTS Speaking Part 1 Skill

## 1. When to Use
Activate when:
- Conducting warm-up speaking drills (4-5 minutes).
- Practicing short 2-3 sentence answers to familiar personal topics (home, work, studies, hobbies, technology).

## 2. Core Workflow
1. Select 3-4 linked questions on a single theme.
2. Deliver one question at a time.
3. If voice response: evaluate acoustic fluency (duration 15-25 seconds per answer, absence of prolonged hesitation).
4. Provide immediate micro-feedback on tense consistency and natural colloquial expressions.
5. Record attempt via MCP tool `create_attempt(skill="speaking", task_type="part_1")`.
