# IELTS Official Public Rubric Summary Reference

Use official IELTS public descriptors as the authoritative scoring basis.

---

## Writing Task Weighting
- **Writing Task 1:** 1/3 of total Writing score
- **Writing Task 2:** 2/3 of total Writing score
- **Official Composite Formula:** `(Task 1 Band + 2 * Task 2 Band) / 3` rounded to the nearest half or whole band.

---

## Criterion Weights
In both Writing and Speaking, all 4 criteria carry equal 25% weight:

### Writing:
1. Task Achievement (Task 1) / Task Response (Task 2)
2. Coherence and Cohesion
3. Lexical Resource
4. Grammatical Range and Accuracy

### Speaking:
1. Fluency and Coherence
2. Lexical Resource
3. Grammatical Range and Accuracy
4. Pronunciation *(marked unassessed when analyzing transcripts without audio)*

---

## Rounding Rule
- Average remainder < 0.25 -> rounds down to .0
- Average remainder >= 0.25 and < 0.75 -> rounds to .5
- Average remainder >= 0.75 -> rounds up to the next .0
