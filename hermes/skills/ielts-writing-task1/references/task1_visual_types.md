# IELTS Writing Task 1 Visual Types and Overview Requirements

Task 1 requires summarizing visual information (minimum 150 words).

---

## 1. Visual Stimulus Types
- **Line Graph:** Focus on chronological trends over time (rise, fall, plateau, fluctuate, peak).
- **Bar Chart:** Compare categories or groups at single or multiple time points.
- **Pie Chart:** Compare proportions or percentages of a total.
- **Table:** Extract significant highs, lows, anomalies, and comparisons.
- **Process Diagram:** Chronological stages from raw input to final product; passive voice is essential.
- **Map / Plan:** Past vs present or proposed developments; prepositions of location and spatial changes.
- **Multiple Charts:** Synthesise relationships between two related visual representations.

---

## 2. The Non-Negotiable Overview Rule
- An overview is an essential requirement.
- It must state the most prominent overall trends, differences, or stages WITHOUT quoting minute data points.
- If no identifiable overview is present, Task Achievement is capped at **Band 5.0 maximum**.
